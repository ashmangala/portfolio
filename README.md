# Asher Mangala's Portfolio Project

A personal portfolio website built with HTML, CSS, JavaScript and Python.
Showcases projects, skills, and contact info in a clean, responsive layout.
## 🚀 Live Demo


## ✨ Features

- **Responsive Design** - works on desktop, tablet, and mobile
- **Project Showcase** - Highlight your work with images and descriptions
- **Skills Section** - List technologies you use
- **Contact Form / Links** - Easy way for people to reach you
- **Lightweight** - Just Flask, vanilla HTML, CSS, and JS

  ## 🛠 Tech Stack

  - **HTML5** - Structure
  - **CSS3** - Styling and responsiveness
  - **JavaScript** - interactivity
  - **Flask** - Backend
